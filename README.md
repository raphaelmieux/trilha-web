# Trilha.Web()

Plataforma de trilha de especialidades para Desbravadores — Líder Máster (AP034) e
Líder Máster Avançado (AP035). Aulas teóricas, laboratórios interativos, acompanhamento
de progresso e emissão/verificação pública de certificado.

> Documentação em construção — este README será completado com instruções de setup,
> arquitetura e deploy ao final da reconstrução do projeto.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (Postgres + Auth + Edge Functions)
